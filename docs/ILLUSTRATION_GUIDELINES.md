## 1. Illustration Design Philosophy

Illustrations in CampusTracker Mobile reinforce brand identity, simplify onboarding workflows, and eliminate visual monotony in empty states. The visual style avoids generic flat clip-art, utilizing **clean 3D-inspired vector geometry**, **soft ambient gradients**, and **subtle glowing glass layers**.

## 3. Empty State Graphic Suite

- **No Notes Yet**: Floating document stack with soft glowing folder backdrop + `"+ Create Note"` CTA button.
- **No Pending Assignments**: Checked clipboard graphic with celebratory stars + `"All Caught Up!"` banner.
- **No Timetable Scheduled**: Blank calendar sheet with camera upload badge + `"Import AI Timetable"` button.

---

## 4. Error & Warning Graphic Suite

- **Offline Network**: Cloud disconnect icon with soft amber glow + `"Working Offline"`.
- **GEOFENCE Out of Range**: Map pin with warning radius ring + `"You must be inside the classroom"`.
- **Camera Permission Denied**: Locked camera lens graphic + `"Enable Camera Access in Settings"`.
